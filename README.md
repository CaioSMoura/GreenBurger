# 🍔 GreenBurger Delivery

Projeto de prototipagem de aplicativo mobile desenvolvido no primeiro semestre da graduação em Ciência da Computação.

## 📌 Descrição
O GreenBurger é um aplicativo de delivery focado em hambúrgueres veganos, com o objetivo de oferecer uma experiência prática e intuitiva para o usuário na escolha de refeições saudáveis.

## 🎯 Objetivo
Desenvolver um protótipo de interface (UI) com foco em usabilidade, organização de informações e experiência do usuário.

## 🛠️ Ferramentas utilizadas
- Figma

## 📱 Funcionalidades
- Tela inicial com apresentação da marca
- Listagem de produtos por categorias
- Barra de busca
- Visualização detalhada do produto
- Informações como preço, avaliação, tempo de entrega e calorias

## 💡 Aprendizados
- Estruturação de layout mobile
- Hierarquia visual e organização de elementos
- Criação de interfaces inspiradas em aplicativos reais
- Noções iniciais de UX/UI Design


## 🚀 Observação
Este projeto foi desenvolvido no início da minha jornada acadêmica e representa minha evolução na área de tecnologia e design de interfaces.
